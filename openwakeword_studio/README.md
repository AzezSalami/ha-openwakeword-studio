# openWakeWord Studio

Wake word detection for Home Assistant's voice assistant, powered by
[openWakeWord](https://github.com/dscripka/openWakeWord) — with a web UI so you
don't have to edit YAML or guess at thresholds.

- **Create your own wake word** right in the add-on: type a phrase, optionally
  record your voice, press *Start training*
- Enable or disable wake words with a switch; upload custom models by drag & drop
- Test in the browser with your microphone or an audio file and watch live scores
- Tune threshold, trigger level, voice activity filter and noise suppression,
  globally or per wake word — changes apply instantly
- See which devices are listening and what was detected, live

Open the add-on's **Documentation** tab for setup instructions.
